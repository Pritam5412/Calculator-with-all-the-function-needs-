# Calculator-with-all-the-function-needs-
Dentaku (電卓) is an all-in-one calculator web app with a Casio-style scientific calculator (trig, logs, factorials, nPr/nCr, memory, fractions, derivatives, integrals, equation solver) plus percentage, EMI, SIP, GST, BMI, age, date difference, unit and number base converters. Pure HTML, CSS and JavaScript.

*Scientific calculator*
1) Trigonometric and hyperbolic functions, with degree, radian and gradian modes
2) Logarithms, powers, roots, factorial, nPr and nCr
3) SHIFT key for second functions
4) Memory variables and Ans
5) Fraction display and result formats (Norm, Fix, Sci, Eng, DMS)
6) Numerical derivative, integral, summation and equation solver
   
*Everyday*: percentage, discount, tip and bill split, unit converter

*Money*: loan EMI, compound interest, SIP, GST/tax

*Health and dates*: BMI, age, date difference

*Programmer*: two-way binary, octal, decimal and hexadecimal converter

*Extras*: dark mode, works on phone and desktop, no libraries or install needed
